RUN THIS HUB LOCALLY

No build step. No dependencies.

From the Hackthon repository root, start Python's built-in static file server:

TERMINAL python -m http.server 8000 --bind 127.0.0.1 Then open http://localhost:8000
!

Keep credentials out of the hub. FreeLLMAPI's key belongs in the environment or configuration of the service/client that needs it—never in this page, a URL, or a committed file. The endpoint is local to your machine; this page makes no API calls.
